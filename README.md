# Emberwatch

[![make.fun · best-game-01](https://make.fun/badge/best-game-01.svg)](https://make.fun/bounty/best-game-01?utm_source=github&utm_medium=readme&utm_campaign=best-game-01)

A tower-defense game built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

The last lantern is lit, and ember wisps are marching for it. Build Spark Lanterns, Frost Runes and Cannon Blooms along their winding path, upgrade them, sell the ones that stop earning — and hold all 10 waves. Three enemy kinds (fast wisps, fluttering hexes, slow brutes), a growing economy, and a win screen only if the lantern survives wave 10.

## Run it

```sh
python3 -m http.server --directory game 8080
# open http://localhost:8080 in desktop Chrome
```

Controls: mouse to build / select towers, `1`/`2`/`3` pick a tower, `Space` start a wave, `U` upgrade, `X` sell, `P` pause, `R` restart, `M` sound.
